# 豆包视频批量生成（Doubao Video Batch）

一个 macOS 本地小工具：你给它**提示词**和**参考图片文件夹**，它自动操作豆包网页版的「AI 创作 → 视频」帮你生成视频。全程固定使用 **Seedance 2.5 · 9:16 竖屏 · 30 秒**，并实时显示进度：豆包要求确认时自动回复继续，失败了自动重试直到生成成功，成功后把无水印视频下载到本机。被豆包下线时会在页面上显示登录二维码，扫码后自动接着跑；遇到验证码会暂停并提醒你手动完成。

> 本工具不是豆包官方产品。它只是代替你在自己的豆包账号里点按钮，生成次数、额度和内容审核仍以豆包为准。

## 功能一览

- **固定参数**：每个任务都强制选 Seedance 2.5、9:16、30s，发送前逐项核对；页面改版或设置没生效时直接报错，不会用错误参数生成。
- **提示词 + 图片文件夹**：自动上传文件夹里的参考图（最多 10 张，豆包的上限）；HEIC、过大的图片会先转成 JPEG（只缩小不放大）。文件夹里放 `prompt.txt` 可自动读取提示词。
- **批量导入**：选一个总文件夹，每个子文件夹算一个任务，排队依次生成。
- **自动确认继续**：豆包先回一段「视频生成参数确认…确认后我再开始生成」时，自动回复「确认，直接生成」。即使提示词里出现「排队、失败、额度」之类的字眼也不会误判。
- **进度提示**：每个任务都有「提交 → 确认 → 生成 → 下载」四步进度，生成中按豆包给的预计时间显示进度条和计时。
- **结果**：成功时显示「成功」，可直接在页面里播放；视频（默认无水印）保存到「影片/豆包视频生成」，旁边附一个同名 `.txt`，记录提示词、豆包回复和对话链接。失败时显示「失败」和豆包的原话。
- **失败自动重试，直到生成成功**：内容审核拒绝、生成失败、豆包没回复等情况会新建对话重试，等待时间逐次加倍（默认 2 分钟起，最长 30 分钟）；下载失败、超时或读取出错时先重新检查原对话，不会重复消耗额度。默认不限次数，可在设置中修改，也可随时取消。
- **额度 / 频繁保护**：豆包提示额度用完时整体暂停提交（默认 60 分钟后再试）；提示「操作太频繁」时也会整体冷却（10 分钟起逐次加倍），避免越重试越被限制。
- **掉线自动处理**：检测到豆包退出登录（比如操作太频繁被下线）后立即暂停提交，先尝试从日常 Chrome 导入登录；不行就在本工具页面顶部**显示豆包登录二维码**并发系统通知。用手机豆包 App 扫码确认后自动继续，二维码过期会自动刷新。
- **验证码处理**：检测到豆包安全验证时暂停所有操作，发系统通知，把自动化 Chrome 窗口切到前台，并在页面上显示验证码截图。**验证码需要你本人手动完成**（工具不会自动破解），完成后自动继续。
- **不打扰日常 Chrome**：工具使用单独的 Chrome 窗口和数据目录，不会动你平时用的 Chrome。

## 零基础使用方法

### 1. 准备

- 一台 Mac（Apple 芯片或 Intel 均可），已安装 [Google Chrome](https://www.google.com/chrome/)。
- 一个可以使用 Seedance 2.5 视频生成的豆包账号。
- Python 3.10 或更高版本。没有的话，`start.command` 会尝试用 Homebrew 自动安装。

### 2. 下载并启动

**方式一：App（推荐）**

在 [Releases](../../releases) 下载 `DoubaoVideoBatch-v版本号-macOS.zip`，解压后把「豆包视频批量生成.app」拖到「应用程序」，双击打开。首次打开会准备运行环境（约 1–3 分钟，需要联网），完成后自动在浏览器中打开页面。App 没有 Dock 图标，退出请在网页底部点「退出程序」。运行数据保存在 `~/Library/Application Support/DoubaoVideoBatch`。

App 未经过 Apple 公证。如果 macOS 提示无法打开，请在「系统设置 → 隐私与安全性」中点「仍要打开」。

**方式二：源码**

1. 打开本仓库页面，点 **Code → Download ZIP** 并解压；或者用 git 克隆。
2. 双击 `start.command`。首次启动会在项目里创建独立的 `.venv` 环境并安装依赖，需要联网，大约 1–3 分钟。
3. 启动完成后浏览器会自动打开 `http://127.0.0.1:8790/`。使用期间请保持弹出的终端窗口开着。

也可以自己运行 `scripts/build_app.sh` 生成 App。

### 3. 登录豆包（只需一次）

第一次添加任务（或点右上角的窗口图标）时，工具会打开一个**独立的 Chrome 窗口**：

- **自动导入（默认）**：如果你日常用的 Chrome 已经登录了豆包，工具会自动把登录状态导入过来。macOS 可能弹出钥匙串对话框，询问是否允许读取「Chrome Safe Storage」，请点「允许」。
- **扫码登录**：如果自动导入失败，本工具页面顶部会出现豆包登录二维码，用手机豆包 App（或飞书 App）扫码并确认即可。

也可以在「设置 → 豆包登录」里手动选择 Chrome 用户导入，或点「扫码登录」。

> 自动化用的 Chrome 窗口请不要关闭，可以最小化。关掉了也没关系，下个任务开始时会自动重新打开。

### 4. 添加任务

**单个任务**：在左侧填写提示词，选择参考图片文件夹，点「加入队列」。

- 提示词里不用写比例和时长，工具会固定设置。
- 文件夹里的图片按文件名自然顺序上传（`1.jpg`、`2.jpg`、`10.jpg`）。超过 10 张会被拒绝，请先挑选。
- 支持 jpg / jpeg / png / webp / apng，heic / heif / gif / bmp / tiff / avif 会自动转换。

**批量导入**：切到「批量导入」，选择一个总文件夹，结构如下：

```text
素材总文件夹/
├── 01-海边/   prompt.txt  a.jpg  b.png
├── 02-街景/   prompt.txt  c.jpg
└── 03-森林/   d.jpg  e.jpg        ← 没有 prompt.txt 时使用「默认提示词」
```

### 5. 查看进度和结果

右侧任务列表会实时更新，可以按「进行中 / 等待重试 / 成功 / 失败」筛选：

| 状态 | 含义 |
| --- | --- |
| 排队中 | 等待前面的任务。默认一次只跑一个，两次提交至少间隔 30 秒，避免被豆包判定频繁 |
| 提交中 | 正在打开 AI 创作、选择模型和参数、上传图片、发送提示词 |
| 等待豆包回复 / 自动确认继续 | 豆包要求确认时自动回复继续 |
| 生成中 | 豆包已经开始生成，显示预计时间和已用时间（Seedance 2.5 通常需要 15 分钟左右） |
| 下载中 → 成功 | 视频已保存，可以直接播放、打开或在 Finder 中显示 |
| 等待重试 | 这次失败了，显示原因和倒计时，到时间自动重试；也可以点「立即重试」 |
| 失败 | 无法重试的错误（如参考图超过 10 张），或已达到设置的重试上限 |

每个任务都可以展开「过程记录」查看每一步和豆包的原话，展开「失败记录」查看每次失败的原因，或点「豆包对话」在网页中查看。

## 设置说明

点右上角齿轮图标：

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 掉线时自动从日常 Chrome 导入登录 | 开 | 关闭后掉线会直接显示二维码 |
| 视频保存位置 | `~/Movies/豆包视频生成` | 视频和同名说明文件保存在这里，保存时会检查是否可写 |
| 自动回复内容 | 确认，直接生成 | 豆包要求确认时发送的内容 |
| 每轮最多自动回复 | 3 次 | 超过后视为「豆包没有开始生成」并重试 |
| 等待回复超时 | 6 分钟 | 发送后迟迟没有回复则重试 |
| 生成超时 | 120 分钟 | 超时后先重新检查原对话，连续 3 次仍没有结果再新建对话 |
| 失败自动重试 / 最多重试次数 | 开 / 0（不限） | 0 表示一直重试到成功 |
| 首次重试等待 / 上限 | 2 / 30 分钟 | 每失败一次等待时间加倍 |
| 额度用完后等待 | 60 分钟 | 额度用完时整体暂停提交，到时间再试 |
| 同时进行的任务数 | 1 | 调大可以并行，但更容易被豆包判定频繁而下线 |
| 两次提交最小间隔 | 30 秒 | 同上，防止操作太频繁 |

## 常见问题

**豆包说「额度已用完」怎么办？**
页面顶部会显示冷却提示，工具按设置的时间间隔自动再试，额度恢复后继续生成。也可以点「立即重试」。

**豆包说内容不符合规范，不能生成？**
会按重试策略新建对话再试。如果一直被拒，建议修改提示词或参考图后点「重试（新对话）」，或直接取消。

**弹出了验证码？**
页面顶部会出现提示和验证码截图，自动化 Chrome 窗口也会切到前台。在 Chrome 里手动完成验证即可，完成后任务自动继续。

**被豆包下线了？**
页面顶部会出现二维码，用手机豆包 App 扫码确认后自动继续；在 Chrome 窗口里直接登录也可以，工具会自动发现。频繁下线时，建议在设置里保持「同时进行的任务数」为 1，并把「两次提交最小间隔」调大。

**生成好的视频在哪？**
默认在「影片 / 豆包视频生成」，点右上角文件夹图标可直接打开。在列表中删除任务不会删除已下载的视频。

**怎么退出？**
在网页底部点「退出程序」，或关闭启动时的终端窗口，或双击 `stop.command`。工具打开的 Chrome 窗口会一起关闭。正在生成的任务下次启动时会继续跟踪。

## 隐私与安全

- 服务只监听本机 `127.0.0.1`，拒绝其他网站发起的跨站请求，页面不允许被嵌入。
- 「从 Chrome 导入登录」只读取 `doubao.com` 的 Cookie，在本机解密后直接交给工具专用的 Chrome，不会写入日志或上传到任何地方。
- 只能预览你选择过的文件夹里的图片，只能打开本工具生成的视频。
- 专用 Chrome 的登录状态、设置、任务记录和日志都保存在 `data/` 目录（App 版在 `~/Library/Application Support/DoubaoVideoBatch`），已加入 `.gitignore`。删除其中的 `chrome-profile` 即可清除工具里的豆包登录。
- 工具不会自动破解验证码，也不会绕过豆包的额度和内容审核。

## 开发

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt pytest
.venv/bin/python -m pytest -q tests
.venv/bin/python -m uvicorn app.server:app --port 8790
```

目录结构：

| 路径 | 作用 |
| --- | --- |
| `app/doubao.py` | 豆包页面自动化：切换视频、选模型、设比例时长、上传、发送、回复 |
| `app/classify.py` | 把豆包对话消息识别为「待确认 / 生成中 / 成功 / 失败（额度、频繁、审核、生成）」 |
| `app/tasks.py` | 任务队列、自动确认、自动重试、冷却、掉线扫码登录、验证码暂停、下载 |
| `app/browser.py` | 启动并连接专用 Chrome（CDP），调用豆包接口，登录校验，验证码检测，下载视频 |
| `app/login.py` | 登录按钮、登录二维码、推广弹窗处理 |
| `app/chrome_cookies.py` | 从日常 Chrome 导入豆包登录 |
| `app/images.py` | 文件夹扫描、图片转换、缩略图 |
| `app/static/` | 网页界面 |
| `scripts/build_app.sh` | 打包 macOS App |
